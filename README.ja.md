# DSH Sync

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

Microsoft アカウントでサインインするだけで、DSH ネイティブの指示とユーザースキルをデバイス間で同期できます。クラウド上のデータは必要に応じて暗号化できます。

**試用版：** 使用前に重要なファイルをバックアップしてください。同期は元のファイルを変更します。本プラグインはバックアップサービスではなく、データ損失を防ぐことを保証するものでもありません。

## 機能

- グローバル指示、プロンプト／フラグメントのテキストファイル、ユーザースキルを各デバイスの元のパスへ自動同期
- 一つのアセット一覧、デバイスごとの除外設定、明示的な競合解決、最大 10 件の破棄バージョンのバックアップ
- パスフレーズと独立した回復キーを使用する、任意の AES-256-GCM 暗号化
- Windows では OS により保護された自動ロック解除、ほかのプラットフォームでは手動ロック解除
- DSH の現在の言語に従う設定画面：英語、簡体字中国語、日本語に対応

会話、認証情報、プラグインのインストール状態、任意のプロジェクト／プロファイルのファイルは同期しません。追加の `.agents` ルートは既定で無効です。内蔵エディター、テキストの自動マージ、チーム共有のワークフローは提供しません。

## はじめに

DSH `0.2.2-rc.1` でテスト済みです。近いバージョンでも動作する可能性はありますが、互換性は保証しません。サインイン時には、ブラウザーと Host が同じコンピューターで動作している必要があります。組織のポリシーにより、同意が制限される場合があります。

1. DSH のプラグインマネージャーでパッケージディレクトリをインストールし、DSH を再起動して、**設定 → DSH Sync** を開きます。
2. Microsoft アカウントでサインインします。ブラウザーが開かない場合は、**Microsoft サインインを開く** を選択してください。
3. **同期アセット** を確認し、ローカルのみに残すものを除外します。新しい保管庫を初期化するか、同じアカウントの既存の保管庫に参加します。正常に動作している保管庫を再初期化しないでください。
4. 暗号化を使用する場合は、12 文字以上のパスフレーズを設定し、一度だけ表示される回復キーを、このデバイスおよび OneDrive とは別の場所に保管してください。既存の暗号化された保管庫では、一度ロックを解除すると、対応する Windows デバイスで自動ロック解除を設定できます。
5. ファイルは通常どおり編集し、デバイスを切り替える前に **同期済み** になるのを待ってください。**表示** を選択すると、Host に登録されたアプリケーションで元のファイルを開きます。

## 設定のナビゲーション

設定は、**概要**、**同期アセット**、**セキュリティ**、**競合**、**バックアップ**の 5 つの横並びのタブに分かれています。設定を開いている間は、タブを切り替えてもフォームの入力内容と競合の選択が保持されます。

通常の説明は、該当する設定項目やカードの見出しの横にある **?** ボタンから確認できます。マウスを重ねるかフォーカスして 500 ミリ秒待つとヘルプが表示され、クリックまたはタップすると表示を固定できます。同じボタンをもう一度クリックするか、ヘルプの外側をクリックするか、Escape キーを押すと閉じます。重要な警告はヘルプに隠さず、引き続き直接表示します。

## サイドバーの状態表示

サイドバーの **その他**／アカウントの起動ボタンの上に状態を表示し、ページが表示されている間は 3 秒ごとに確認します。マウスを重ねるかキーボードでフォーカスすると説明を確認できます。同期中、競合、保管庫のロック、アセット一覧の警告、読み込み中、接続失敗、サインイン／セットアップが必要な状態、同期の一時停止、未同期の変更、エラーを区別し、同期済みとは誤表示しません。Windows デスクトップでは、サイドバーを折りたたむと表示が隠れます。

定期的な差分確認では、ローカルファイルを比較し、OneDrive の保管庫マーカー、ヘッド項目、スナップショットのメタデータを再確認します。スナップショットに変更がなければ、現在の表示状態を維持し、同期中の回転アイコンは表示しません。新しいリビジョンのダウンロード、変更の公開、クラウドの変更のローカル適用時には同期中と表示し、エラー、競合、保管庫のロックも引き続き通知します。

クリックすると、**設定 → DSH Sync** と同じすべての同期操作を備えたプラグイン独自のダイアログが開きます。開くだけでは同期は実行されません。DSH `0.2.2-rc.1` には特定の設定セクションを開く公開ナビゲーション API がないため、独立したダイアログを使用します。

## セキュリティ境界と制限

- **ローカルファイルは平文のままです。** クラウド暗号化は、侵害された Host、ローカルの作業ファイル、会話に既に読み込まれた指示を保護しません。
- **Microsoft のアクセス権限は同期フォルダーより広範です。** 委任された `Files.ReadWrite` 権限によるアクセスをそのフォルダーに限定するのは、プラグイン自身の動作であり、Microsoft の権限境界による強制ではありません。サインイントークンは DSH の認証情報サービスに保存されますが、既定のファイルベースのプロバイダーは OS のキーチェーンではありません。
- **回復手段を安全に保管してください。** 利用可能な信頼済みデバイス、パスフレーズ、回復キーがすべて失われると、暗号化された保管庫は復旧できません。パスフレーズを変更しても、既にマスターキーを保持しているデバイスのアクセス権は取り消されません。暗号化の変更が OneDrive で成功してもローカル処理を完了できなかった場合は、警告とともに表示される新しいキーを保存してください。クラウドの変更は取り消されません。ローカルのアクセスやストレージの問題を解決してから、更新して同期してください。
- **除外設定はデバイスごとです。** 除外を確定すると、このデバイスの元ファイルは残りますが、現在のクラウドコピーは削除されます。ほかのデバイスは削除を反映する場合も、ファイルを再アップロードする場合もあります。クラウドの履歴には古いコピーが残る可能性があります。
- **独立したバックアップを用意してください。** 複数ファイルの更新はファイルシステムのトランザクションではありません。POSIX の実行ビットを含め、ファイルのアクセス許可は同期されません。同期した指示やスクリプトは使用前に確認してください。

自動ロック解除には、Windows CurrentUser DPAPI と標準の Windows PowerShell が必要です。**保管庫をロック** すると、再起動後もロックされたままです。自動ロック解除を無効にすると、保存されたロック解除能力は削除されますが、現在のセッションはロックされません。対応する OS 保護を利用できない場合は手動で解除する必要があり、平文のキーキャッシュにフォールバックすることはありません。
