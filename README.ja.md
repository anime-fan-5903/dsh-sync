# DSH Sync

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

Microsoft アカウントでサインインして、DSH ネイティブの指示、ユーザースキル、確認済みの DSH オプション、および任意のモデル設定をデバイス間で同期できます。クラウド上のデータは必要に応じて暗号化できます。

**試用版：** 使用前に重要なファイルをバックアップしてください。同期は元のファイルを変更します。本プラグインはバックアップサービスではなく、データ損失を防ぐことを保証するものでもありません。

## 機能

- グローバル指示、プロンプト／フラグメントのテキストファイル、ユーザースキルを各デバイスの元のパスへ自動同期
- 一つのアセット一覧、デバイスごとの除外設定、明示的な競合解決、最大 10 件の破棄バージョンのバックアップ
- 任意の registry プラグイン一覧と公式組み込みオプションの有効化状態の同期、サイドバー通知、ローカル確認後の復元
- パスフレーズと独立した回復キーを使用する、任意の AES-256-GCM 暗号化
- Windows では OS により保護された自動ロック解除、ほかのプラットフォームでは手動ロック解除
- DSH の現在の言語に従う設定画面：英語、簡体字中国語、日本語に対応

会話、認証情報、インストール済みパッケージのファイル、任意のプロジェクト／プロファイルのファイルは同期しません。設定の同期は以下の確認済みフィールドに限定され、任意のプラグイン一覧同期はローカル確認後の復元に対応します。追加の `.agents` ルートは既定で無効です。内蔵エディター、テキストの自動マージ、チーム共有のワークフローは提供しません。

## はじめに

DSH `0.2.2-rc.1` でテスト済みです。近いバージョンでも動作する可能性はありますが、互換性は保証しません。サインイン時には、ブラウザーと Host が同じコンピューターで動作している必要があります。組織のポリシーにより、同意が制限される場合があります。

1. DSH のプラグインマネージャーでパッケージディレクトリをインストールし、DSH を再起動して、**設定 → DSH Sync** を開きます。
2. Microsoft アカウントでサインインします。ブラウザーが開かない場合は、**Microsoft サインインを開く** を選択してください。
3. **同期対象** と **同期アセット** を確認し、ローカルのみに残すものを除外します。新しい保管庫を初期化するか、同じアカウントの既存の保管庫に参加します。正常に動作している保管庫を再初期化しないでください。
4. 暗号化を使用する場合は、12 文字以上のパスフレーズを設定し、一度だけ表示される回復キーを、このデバイスおよび OneDrive とは別の場所に保管してください。既存の暗号化された保管庫では、一度ロックを解除すると、対応する Windows デバイスで自動ロック解除を設定できます。
5. ファイルは通常どおり編集し、デバイスを切り替える前に **同期済み** になるのを待ってください。**表示** を選択すると、Host に登録されたアプリケーションで元のファイルを開きます。

## 設定のナビゲーション

設定は、**概要**、**同期対象**、**同期アセット**、**セキュリティ**、**競合**、**バックアップ**の 6 つの横並びのタブに分かれています。設定を開いている間は、タブを切り替えてもフォームの入力内容と競合の選択が保持されます。

### 同期対象

プロンプト、スキル、DSH オプションは既定で有効、モデル設定とプラグインは無効です。ローカルでモデルやプラグインの同期を有効にする場合はリスクを確認します。共有設定で選択を他のデバイスに引き継げますが、プラグインのインストールとモデル変更の適用は引き続きローカルで確認します。独立した `.agents` の参加設定は既定で無効です。

カテゴリを無効にしてもローカルとクラウドのコピーは残ります。再度有効にすると基準をリセットして差分を確認します。これは、現在のクラウドコピーを削除する、明示的に確認したファイル単位の除外とは異なります。対象の選択を共有しても、実行時の範囲確認フラグ自体はローカルに残ります。

DSH オプションは固定の許可リストを使用します。対象は `locale.preference`、`ui-theme` の外観設定と本文・コード・ターミナルの文字サイズ、`ui-chat` の会話表示・折りたたみ時機・返信の折りたたみ・性能情報の表示設定です。確認済みのユーザー上書き値のみを出力し、schema 全体や任意の profile 設定は出力しません。認証情報、セキュリティポリシー、デバイスのパス、インストール権限はローカルに残ります。

モデル設定は `llm-deepseek`、`llm-deepseek-api-key`、`llm-pi-ai` の移植可能な一部を対象とし、対応するエンドポイント、モデル定義、一部の推論／転送パラメーターを含みます。API キー、トークン、`apiKeyEnv` による認証情報の関連付け、カスタムヘッダーは含みません。ローカルでの有効化にはリスクの確認が必要です。**受信したすべてのモデル変更は適用待ちとして保存**され、エンドポイントの変更に限らず、内容のフィンガープリントに紐づく明示的なローカル確認が必要です。エンドポイントの変更によって、会話や既存のローカルキーが別のホストに送信される可能性があります。暗号化は接続の安全性を保証しません。

設定の競合はフィールド単位ではなく名前空間単位で解決します。適用時はリビジョンを確認してフィールド単位で変更し、ローカルの秘密情報や無関係な設定を保持します。モデルアセットの同期完了は、確認待ちの変更が適用済みであることを意味しません。

### DSH Sync 設定の同期

**DSH Sync 設定の同期**（`syncConfig`）は既定で有効で、保管庫全体で共有するスイッチです。5 種類の同期対象とは独立して、スイッチ自身の状態は常に同期に参加します。無効な間は他の DSH Sync 設定をアップロードも適用もせず、ローカルとクラウドのコピーを残します。他のデバイスから再度有効にできます。無効状態を設定本体より先に処理し、再有効化時は差分を再比較するため、その間のローカル変更を無条件でクラウドへ上書きしません。

共有対象は 5 種類の対象フラグ、自動アセット同期、および間隔（`intervalSeconds`、5–3600 秒）です。選択をまだ変更していない新しいデバイスは、ロック解除済みの最初の成功した同期でクラウド設定を引き継ぎ、対象を一つずつ選び直す必要はありません。既存の選択や明示的な変更は通常の競合解決に従います。認証情報、ロック解除キャッシュ、デバイス信頼、`.agents` の許可、除外設定、プラグインの無視／結果、インストール承認はローカルに残ります。

自動アセット同期を一時停止しても、サインインかつロック解除済みの場合は最小限の設定確認を続けます。通常アセットの基準とクラウドコピーを維持し、ローカルのアセット変更の公開や受信した通常アセットの適用は行いません。サインアウトや保管庫のロックは迂回しません。

通常の説明は、該当する設定項目やカードの見出しの横にある **?** ボタンから確認できます。マウスを重ねるかフォーカスして 500 ミリ秒待つとヘルプが表示され、クリックまたはタップすると表示を固定できます。同じボタンをもう一度クリックするか、ヘルプの外側をクリックするか、Escape キーを押すと閉じます。重要な警告はヘルプに隠さず、引き続き直接表示します。

## サイドバーの状態表示

サイドバーの **その他**／アカウントの起動ボタンの上に状態を表示し、ページが表示されている間は 3 秒ごとに確認します。マウスを重ねるかキーボードでフォーカスすると説明を確認できます。同期中、競合、保管庫のロック、アセット一覧の警告、読み込み中、接続失敗、サインイン／セットアップが必要な状態、同期の一時停止、未同期の変更、エラーを区別し、同期済みとは誤表示しません。Windows デスクトップでは、サイドバーを折りたたむと表示が隠れます。

定期的な差分確認では、ローカルファイルを比較し、OneDrive の保管庫マーカー、ヘッド項目、スナップショットのメタデータを再確認します。スナップショットに変更がなければ、現在の表示状態を維持し、同期中の回転アイコンは表示しません。新しいリビジョンのダウンロード、変更の公開、クラウドの変更のローカル適用時には同期中と表示し、エラー、競合、保管庫のロックも引き続き通知します。

未処理のプラグイン差分がある場合、左下の状態バッジから簡潔なプラグイン復元パネルを直接開けます。それ以外は **設定 → DSH Sync** と同じすべての同期操作を表示します。どちらの画面も、開くだけではインストールしません。DSH `0.2.2-rc.1` には特定の設定セクションを開く公開ナビゲーション API がないため、プラグイン独自のダイアログを使用します。

### プラグインの復元

参加するデバイスの **同期対象** で **プラグイン** を有効にすると、対象となる profile 内の registry バンドルを、新たにインストールしたものも含めて自動検出し、一覧を出力します。各項目にはパッケージ名、正確なバージョン、希望する有効／無効状態を含みます。**自動承認レビュー**を含む公式組み込みオプションの有効／無効状態も、バージョンを固定せずに共有します。対象デバイスに同じ組み込みプラグインがある場合は、ローカル確認後にスイッチを変更します。含まれない場合は同期でインストールしません。共有するのはバンドルのスイッチであり、セッションの権限モードやプラグイン設定ではありません。有効化してもセッションの Auto は選択されず、無効化は実行中のセッションに影響する場合があります。非オプションのコアバンドル、DSH Sync 自体、ローカルパス・Git・tarball・エイリアスは引き続き対象外です。組み込みスイッチを共有する前に、すべての参加デバイスで DSH Sync を更新してください。旧版はこれらの項目を含むスナップショットを拒否し、項目を黙って破棄することはありません。パッケージファイル、registry の URL、認証情報、ビルドスクリプトの許可、互換性の例外は転送しません。復元には対象デバイスで設定された registry を使用します。

バックグラウンドの比較で未処理一覧を自動生成するため、手動で計画を作成したり設定ページを開いたりする必要はありません。インストール可能な不足 registry パッケージ、正確なバージョンが一致する registry の有効／無効変更、条件を満たす組み込みスイッチは既定で選択されます。名前、バージョン、取得元、状態を確認して **選択項目を確認して適用** を押すと、一度の明示的なローカル確認で実行できます。承認は表示された希望状態とローカル状態のフィンガープリントに限定され、変更後の古い選択は拒否されます。既存のバージョンや取得元が異なる場合は DSH のプラグインマネージャーで手動処理します。自動のアップグレード、ダウングレード、アンインストールは行いません。

選択した変更がすべて正常に適用されると、復元ダイアログは自動的に閉じます。失敗、古い選択、再起動が必要な結果では確認のため開いたままにし、設定ページ内のパネルは表示を維持します。**後で** はパネルを閉じますが、バッジは残します。項目の無視はこのデバイスとそのフィンガープリントに限られ、新しいバージョンやローカル状態の変更で再び通知されることがあります。ローカルにないパッケージも希望一覧に残り、削除として公開されません。進捗、失敗、スクリプトの拒否、非互換性、再起動の必要性は、クラウド同期とは別に表示します。既に許可されたインストールスクリプトは実行される場合があります。新しいスクリプト許可と互換性の例外には、DSH のプラグインマネージャーで別途承認が必要です。パネルを閉じても、承認済みのインストールは中止されません。

## セキュリティ境界と制限

- **ローカルファイルは平文のままです。** クラウド暗号化は、侵害された Host、ローカルの作業ファイル、会話に既に読み込まれた指示を保護しません。
- **Microsoft のアクセス権限は同期フォルダーより広範です。** 委任された `Files.ReadWrite` 権限によるアクセスをそのフォルダーに限定するのは、プラグイン自身の動作であり、Microsoft の権限境界による強制ではありません。サインイントークンは DSH の認証情報サービスに保存されますが、既定のファイルベースのプロバイダーは OS のキーチェーンではありません。
- **回復手段を安全に保管してください。** 利用可能な信頼済みデバイス、パスフレーズ、回復キーがすべて失われると、暗号化された保管庫は復旧できません。パスフレーズを変更しても、既にマスターキーを保持しているデバイスのアクセス権は取り消されません。暗号化の変更が OneDrive で成功してもローカル処理を完了できなかった場合は、警告とともに表示される新しいキーを保存してください。クラウドの変更は取り消されません。ローカルのアクセスやストレージの問題を解決してから、更新して同期してください。
- **除外設定はデバイスごとです。** 除外を確定すると、このデバイスの元ファイルは残りますが、現在のクラウドコピーは削除されます。ほかのデバイスは削除を反映する場合も、ファイルを再アップロードする場合もあります。クラウドの履歴には古いコピーが残る可能性があります。
- **独立したバックアップを用意してください。** 複数ファイルの更新はファイルシステムのトランザクションではありません。POSIX の実行ビットを含め、ファイルのアクセス許可は同期されません。同期した指示やスクリプトは使用前に確認してください。

自動ロック解除には、Windows CurrentUser DPAPI と標準の Windows PowerShell が必要です。**保管庫をロック** すると、再起動後もロックされたままです。自動ロック解除を無効にすると、保存されたロック解除能力は削除されますが、現在のセッションはロックされません。対応する OS 保護を利用できない場合は手動で解除する必要があり、平文のキーキャッシュにフォールバックすることはありません。
