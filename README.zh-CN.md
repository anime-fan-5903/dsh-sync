# DSH Sync

[English](README.md) | **简体中文** | [日本語](README.ja.md)

登录 Microsoft 账户，即可在设备间同步 DSH 原生指令、用户 Skills、经过审核的 DSH 选项及可选的模型配置，支持可选的云端加密。

**试用版本：** 使用前请备份重要文件。同步会修改原始文件，本插件不是备份服务，也不保证数据不会丢失。

## 功能

- 自动将全局指令、提示词／片段文本文件和用户 Skills 同步至各设备的原始路径
- 统一的资产列表、设备本地排除规则、明确的冲突选择，以及最多十份被舍弃版本的备份
- 可选的 registry 插件清单同步，支持侧栏提醒及本地确认后恢复
- 可选的 AES-256-GCM 加密，使用口令和独立的恢复密钥
- Windows 上由系统保护的自动解锁；其他平台使用手动解锁
- 设置页面跟随 DSH 当前语言，支持英文、简体中文和日文

不会同步会话、凭据、已安装的包文件，以及任意项目或 profile 文件；配置同步仅限下述经过审核的字段，可选的插件清单同步支持经本地确认后恢复。额外的 `.agents` 根目录默认关闭。不提供内置编辑器、文本自动合并或团队共享工作流。

## 开始使用

已在 DSH `0.2.2-rc.1` 上测试。相近版本可能兼容，但不保证。登录时，浏览器与 Host 必须运行在同一台计算机上。组织策略可能限制授权。

1. 通过 DSH 插件管理器安装插件包目录，重启 DSH，然后打开 **设置 → DSH Sync**。
2. 使用 Microsoft 账户登录。如果浏览器未打开，请点击 **打开 Microsoft 登录页面**。
3. 检查 **同步目标** 和 **同步资产**，并排除应仅保留在本地的内容。初始化新保险库，或加入同一账户下已有的保险库；请勿重新初始化正常使用中的保险库。
4. 如需加密，请设置至少 12 个字符的口令，并将仅显示一次的恢复密钥与此设备和 OneDrive 分开保存。对于已有的加密保险库，在受支持的 Windows 设备上解锁一次即可建立自动解锁。
5. 按平时的方式编辑文件，切换设备前请等待状态变为 **已同步**。点击 **查看** 可通过 Host 注册的应用打开原始文件。

## 设置导航

设置按六个横向标签页组织：**概览**、**同步目标**、**同步资产**、**安全**、**冲突**和**备份**。设置保持打开期间，切换标签页会保留表单输入和冲突选择。

### 同步目标

提示词、Skills 和 DSH 选项默认开启；模型配置和插件默认关闭。在本机开启模型或插件同步时需要确认风险。共享偏好可以将这些选择带到其他设备，但插件安装和模型应用仍需本机确认。独立的 `.agents` 参与开关仍默认关闭。

关闭类别会保留本地和云端副本；重新开启会重置基线并重新检查差异。这不同于经过明确确认的单文件排除操作，后者会删除当前云端副本。目标选择可以共享，但运行时的范围确认标记本身仍保留在本机。

DSH 选项使用固定允许列表：`locale.preference`；`ui-theme` 的外观偏好及正文、代码和终端字号；`ui-chat` 的会话显示、折叠时机、回复折叠和性能信息显示偏好。只导出经过审核的用户覆盖值，不导出整个 schema 或任意 profile 配置。凭据、安全策略、设备路径和安装权限保留在本地。

模型配置支持 `llm-deepseek`、`llm-deepseek-api-key` 和 `llm-pi-ai` 的可迁移子集，包括受支持的端点、模型定义和部分推理／传输参数。不包含 API 密钥、令牌、`apiKeyEnv` 凭据绑定或自定义请求头。在本机开启时需要确认风险。**所有传入的模型变更均先暂存**，必须在本地进行与内容指纹绑定的明确确认，不仅限于端点变更。更改端点可能将对话和已有的本地密钥发送到其他主机；加密并不意味着该连接安全。

配置以命名空间为单位解决冲突，而非逐字段合并冲突。应用时使用带修订号检查的字段级修改，保留本地秘密和无关设置。模型资产已同步，不代表待确认的更改已经生效。

### DSH Sync 配置同步

**DSH Sync 配置同步**（`syncConfig`）默认开启，是整个保险库共享的开关。开关自身始终参与同步，不受五类目标限制。关闭后，其他 DSH Sync 偏好不上传、不应用，本地和云端副本均保留；其他设备可以重新开启。关闭状态先于配置内容处理，重新开启后会重新比较差异，不会将关闭期间的本地修改直接排队覆盖云端。

共享允许列表为五类目标的勾选状态、自动资产同步开关及同步间隔（`intervalSeconds`，5–3600 秒）。未修改过选择的新设备在首次成功且已解锁的同步中沿用云端偏好，无须逐项重新勾选；已有或明确修改过的选择按正常冲突机制处理。凭据、解锁缓存、设备信任、`.agents` 授权、排除规则、插件忽略／结果和安装授权仍保留在本机。

暂停自动资产同步后，已登录且已解锁时仍执行最小配置检查。这类检查保留普通资产的基线和云端副本，不上传本地资产修改，也不应用传入的普通资产；不会绕过退出登录或保险库锁定。

普通说明收纳在对应选项或卡片标题旁的 **?** 按钮中。悬停或聚焦 500 毫秒后显示帮助气泡；点击或轻触可固定气泡以便阅读。再次点击问号、点击气泡外部或按 Escape 可关闭。关键警告仍直接显示，不会隐藏在帮助气泡中。

## 侧栏状态

侧栏 **更多**／账户入口上方的实时状态项，会在页面可见时每三秒检查一次状态。鼠标悬浮或键盘聚焦可查看说明。它区分同步中、冲突、保险库锁定、资产清单警告、加载中、连接失败、需要登录／设置、同步暂停、更改待同步和错误，不会将这些状态误报为已同步。Windows 桌面端收起侧栏后会隐藏此入口。

周期性差异检查会比较本地文件，并重新检查 OneDrive 保险库标记、头项目及快照的元数据；快照未变化时保持当前可见状态，不显示同步旋转图标。下载新版本、发布更改或将云端更改应用到本地时才报告同步中；错误、冲突和保险库锁定仍会正常提示。

存在待处理的插件差异时，左下角状态徽标会直接打开简洁的插件恢复面板；否则打开与 **设置 → DSH Sync** 相同的完整同步控件。仅打开任一视图都不会安装插件。采用插件自己的独立对话框，是因为 DSH `0.2.2-rc.1` 没有公开的指定设置分区导航 API。

### 插件恢复

在参与设备的 **同步目标** 中开启 **插件** 后，符合条件、安装于 profile 的 registry 插件包会被自动发现并导出，包括后来新安装的包。每条清单记录包含包名、准确版本和期望的启用状态。不包含 DSH Sync 自身、随程序分发的核心包，以及本地路径、Git、tarball 或别名来源。不会传输包文件、registry 地址、凭据、构建脚本授权或兼容性豁免；恢复时使用目标设备配置的 registry。

后台比较会自动生成待处理列表，无需手动创建计划或进入设置页。可安装的缺失包和准确版本一致的启停状态变更默认勾选。审阅包名、版本、来源和启用状态后，点击 **确认并应用所选项** 即完成一次明确的本地确认。该确认只授权所显示的期望状态与本地状态指纹，内容变化后旧选择会被拒绝。已有包的版本或来源不一致时，必须在 DSH 插件管理器中手动处理，不会自动升级、降级或卸载。

**稍后** 会关闭面板但保留徽标。忽略某项只对本设备和该指纹生效，新版本或本地状态变化可再次提醒。本地缺失的包仍保留在期望清单中，不会作为删除发布。面板将进度、失败、脚本阻止、不兼容和需要重启分别显示，不等同于云端同步成功。已有许可的安装脚本可能执行；新增脚本权限和兼容性豁免需要通过 DSH 插件管理器另行批准。关闭面板不会取消已经授权的安装。

## 安全边界与限制

- **本地文件仍是明文。** 云端加密无法保护已被入侵的 Host、本地工作文件或已经载入会话的指令。
- **Microsoft 授权范围大于同步文件夹。** 委派的 `Files.ReadWrite` 权限由插件自身的行为限制在该文件夹内，而非由 Microsoft 的权限边界强制限制。登录令牌使用 DSH 凭据服务保存，其默认的文件存储后端并不是操作系统密钥链。
- **请妥善保管恢复材料。** 如果没有可用的受信任设备、口令或恢复密钥，将无法恢复加密保险库。更改口令不会撤销已持有主密钥的设备的访问权限。如果加密更改已在 OneDrive 中成功发布，但本地操作未完成，请保存警告中显示的新密钥；云端更改不会回滚。修复本地访问或存储问题后，请刷新并同步。
- **排除规则仅对当前设备生效。** 确认排除会保留此设备上的原始文件，但会删除当前云端副本。其他设备可能应用该删除操作，也可能重新上传文件；云端历史记录仍可能保留旧副本。
- **请保留独立备份。** 多文件更新不是文件系统事务。文件权限（包括 POSIX 可执行位）不会同步。使用同步的指令和脚本前请先审阅。

自动解锁需要 Windows CurrentUser DPAPI 和系统自带的 Windows PowerShell。**锁定保险库** 后，重启仍会保持锁定；关闭自动解锁会移除持久保存的解锁能力，但不会锁定当前会话。如果系统保护不可用，必须手动解锁，不会回退为明文密钥缓存。
